MyStatTest это бот репититор.

Состоит из заранее заготовленных ответов на команду типа /help и ИИ сгенерированных на остальные.

Генерация ответов идёт по такому pypeline`у:

1. Извлечение токена бота, ключа от ИИ и название модели config`ом из env.
2. Использование данных config`а для создания функции ask_ai для обращения к модели.
3. Обращение к модели через OpenRouter и фильтрация RAW Json формата в читаемый текст.
4. Возврат пользователю.

Команды:
/ai [вопрос] - задать вопрос ИИ
/help        - помощь по командам
/quiz [тема] - сделать мини тест по теме(может быть пустым)
/clear       - очистить историю сообщений
/formulas    - сводка по теме
